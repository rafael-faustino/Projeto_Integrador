⌘ PESQUISA DE PROGRAMAÇÃO E CRIPTOGRAFIA

Aula 1 — Criptografia de Números

Nesta aula, aprendemos uma forma simples de criptografar números. O programa percorre cada algarismo de uma senha, transforma-o em número inteiro, soma 1 e depois junta os novos valores para formar a senha criptografada. 

print("--- Resultado da Aula 1 ---")

senha_numerica = "123456"
senha_num_criptografada = ""

for numero in senha_numerica:
    numero_somado = int(numero) + 1
    senha_num_criptografada = senha_num_criptografada + str(numero_somado)

print(f"Senha original: {senha_numerica}")
print(f"Senha criptografada: {senha_num_criptografada}")
print("-" * 30)

Resultado da Aula 1

--- Resultado da Aula 1 ---
Senha original: 123456
Senha criptografada: 234567
------------------------------

Conclusão: aprendemos a utilizar estruturas de repetição, conversão de tipos e concatenação de textos para transformar uma sequência numérica.

Aula 2 — Convertendo Letras em Números (Cifra de César)

Nesta aula, aprendemos como transformar letras em códigos numéricos utilizando a tabela ASCII e como aplicar a Cifra de César. O método consiste em deslocar cada letra do alfabeto uma posição para frente. Por exemplo, a letra "a" vira "b", a letra "b" vira "c" e assim sucessivamente. 

print("\n--- Resultado da Aula 2 ---")

# Tabela ASCII
alfabeto = "abcdefghijklmnopqrstuvwxyz"

print("Tabela de conversão ASCII de exemplo:")
for letra in alfabeto[:5]:
    numero = ord(letra)
    print(f"  Letra: {letra} -> Código ASCII: {numero}")

print("  ...")

# Dicionário rotacionado
dicionario = "bcdefghijklmnopqrstuvwxyza"

# Função para codificar o texto
def codifica(senha):
    senha_criptografada = ""

    for letra in senha:
        if "a" <= letra <= "z":
            posicao = ord(letra) - ord("a")
            senha_criptografada += dicionario[posicao]
        else:
            senha_criptografada += letra

    return senha_criptografada

# Teste prático
texto_teste = "rafael"
resultado = codifica(texto_teste)

print(f"\nTexto original: {texto_teste}")
print(f"Texto criptografado: {resultado}")
print("-" * 30)

Conclusão: aprendemos a utilizar a função ord() para obter o código numérico de uma letra, a função lenógica de repetição e um dicionário para substituir cada letra por outra. Também vimos como criar funções em Python para organizar o código.

Conclusão Geral

As duas aulas demonstraram como a programação pode ser utilizada para criar métodos simples de criptografia. Na primeira aula, trabalhamos com números, enquanto na segunda utilizamos letras e códigos ASCII. Essas atividades ajudaram a desenvolver o raciocínio lógico e a compreender melhor estruturas de repetição, funções, variáveis e manipulação de dados em Python.
