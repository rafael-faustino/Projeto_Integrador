Robótica: Criptografia de Dados em Python

Pesquisa prática sobre proteção de sinais e senhas utilizando lógica de programação e Cifra de César.

Aula 1 — Criptografia de Números

Cada dígito da senha original é convertido para inteiro, somado a 1 e remontado como texto.

Ver código original em Python (Aula 1) 
senha_numerica = "123456"
senha_num_criptografada = ""

for numero in senha_numerica:
    numero_somado = int(numero) + 1
    senha_num_criptografada = senha_num_criptografada + str(numero_somado)

print(f"Senha original: {senha_numerica}")
print(f"Senha criptografada: {senha_num_criptografada}")

Aula 2 — Cifra de César e Tabela ASCII

Conversão de caracteres utilizando o deslocamento de 1 posição no alfabeto através do código ASCII.

Ver código original em Python (Aula 2) 
dicionario = "bcdefghijklmnopqrstuvwxyza"

def codifica(senha):
    senha_criptografada = ""
    for letra in senha:
        if "a" <= letra <= "z":
            posicao = ord(letra) - ord("a")
            senha_criptografada += dicionario[posicao]
        else:
            senha_criptografada += letra
    return senha_criptografada

print(codifica("rafael"))
